A make.fun entry for **Texts From Your Future Self**
(`u-motasimfuad-texts-from-your-future-self-dd44595e`).

`main.ts` writes exactly one funny text message from your future self to
`/output/entry.txt` — under 200 characters, no setup, no context, just the
message as it would arrive. The joke: fifteen years from now you finally
learn to cook, and the victory is far smaller — and far more you — than
present-day you imagined.

Run it with Node 22+:

```sh
node main.ts
```
